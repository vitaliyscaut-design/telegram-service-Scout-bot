TELEGRAM-БОТ ДЛЯ ДІАГНОСТИКИ ТРАКТОРА

ЩО ВМІЄ
- Читає базу з Excel «Для Бота2.xlsx».
- Меню: Категорія → Проблема → Причина/несправність.
- Показує спосіб виявлення та шлях усунення.
- Відображає лише ті маршрути, де в таблиці стоїть «Так»:
  Самостійно / Майстер / Сервіс.
- Може надсилати сервісну заявку адміністратору, якщо налаштовано ADMIN_CHAT_ID.

ПІДГОТОВКА НА WINDOWS
1. Встановіть Python 3.11 або новіший з python.org. Під час інсталяції відмітьте Add Python to PATH.
2. Розпакуйте архів в окрему папку.
3. Скопіюйте ваш файл «Для Бота2.xlsx» у цю саму папку, поруч із bot.py.
4. Відкрийте термінал / командний рядок у цій папці.
5. Виконайте:
   py -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
6. Створіть файл .env на основі .env.example та вставте токен бота в TELEGRAM_BOT_TOKEN.
   ВАЖЛИВО: нікому не надсилайте токен і не публікуйте його.
7. Для автоматичної передачі заявок адміністратору вкажіть ADMIN_CHAT_ID.
   Щоб дізнатися ID: напишіть боту /start, а для отримання ID можна тимчасово додати в код
   логування update.effective_user.id або скористатися власним Telegram ID-ботом.
   Якщо бот має надсилати заявки в групу, додайте його до групи й задайте ID групи.
8. У PowerShell/CMD перед запуском задайте змінні середовища:
   $env:TELEGRAM_BOT_TOKEN="ваш_токен"
   $env:ADMIN_CHAT_ID="ваш_chat_id"
   python bot.py
   У звичайному CMD замість $env:... використовуйте set TELEGRAM_BOT_TOKEN=... та set ADMIN_CHAT_ID=...

ЗАПУСК
   python bot.py
Поки вікно термінала відкрите і комп’ютер увімкнений з інтернетом, бот працює. Для цілодобової роботи
його потрібно розмістити на сервері/VPS або хмарному хостингу.

ФОРМАТ EXCEL
Перший аркуш має містити заголовки:
Категорія | Проблема | Причина/Несправність | Спосіб виявлення | Шлях усунення | Самостійно | Майстер | Сервіс
Порожні значення в колонках «Спосіб виявлення» та «Шлях усунення» допустимі.
Для кнопок маршрутів використовуйте «Так»; «Ні» та «-» означають, що кнопку не показувати.

ПРИМІТКА
Поточний варіант читає Excel-файл локально. Зміни у файлі підхопляться після перезапуску бота.
Підключення Google Sheets можна зробити окремим наступним кроком.
